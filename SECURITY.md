| Version | Supported          |

## Reporting a Vulnerability

### Private Repository Security

Since this is a **private repository**, security is our top priority. If you discover a security vulnerability, please follow these steps:

### 1. Do Not Create Public Issues

**Never** open a public issue for security vulnerabilities, even in this private repository. Sensitive information could be exposed.

### 2. Report Privately

Contact the repository owner directly through one of these secure channels:

- **GitHub**: Open a private security advisory (if enabled)
- **Email**: [Your secure email address]
- **Direct Message**: [Your preferred secure communication method]

### 3. Include in Your Report

When reporting a vulnerability, please include:

- **Description**: Clear explanation of the vulnerability
- **Location**: File(s) and line number(s) affected
- **Impact**: Potential security impact and severity
- **Steps to Reproduce**: Detailed steps to reproduce the issue
- **Proof of Concept**: Code or screenshots demonstrating the issue (if applicable)
- **Suggested Fix**: Your recommendation for fixing it (if any)
- **Environment**: Version, dependencies, configuration where found
